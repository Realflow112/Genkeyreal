STEP 1: FIREBASE REALTIME DATABASE CONFIGURATION

  1. Navigate to Firebase Console and click Create a project.
  2. In the sidebar, navigate to Build → Realtime Database → Click Create Database (Select US-Central or nearest region).
  3. Under Rules tab, set read/write permissions for license validation or restrict as preferred:
{
  "rules": {
    "keys": {
      ".read": true,
      ".write": true
    },
    "apps": {
      ".read": true,
      ".write": true
    },
    "logs": {
      ".read": true,
      ".write": true
    }
  }
}

Click Publish. Copy your Web App config credentials into the app settings cog.

STEP 2: GITHUB REPO INITIALIZATION & PUSH

Push this single-file web application to your GitHub repository:

# In your project folder:
git init
git add index.html
git commit -m "feat: Mil-spec Cyberpunk Key Manager & Firebase API"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/cyberpunk-key-manager.git
git push -u origin main

STEP 3: INSTANT VERCEL DEPLOYMENT

  1. Open Vercel.com and sign in with GitHub.
  2. Click Add New → Project, then select your cyberpunk-key-manager repository.
  3. Leave build settings as default (Static HTML) and click Deploy.
  4. Your custom HTTPS dashboard is instantly globally live on Vercel Edge Network!
